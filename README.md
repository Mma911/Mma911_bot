# SCDP Deriv Cloud Server v4.4.0 — وضعا Real وDemo السحابيان

## ما الجديد وما بقي كما هو

يضيف هذا الإصدار محرك Demo اختيارياً داخل خدمة الخادم نفسها، مع إبقاء اتصال Real وإعداداته الحالية كما هي: **PAT → طلب OTP عبر REST → WebSocket الحقيقي**. يستخدم كل حساب عميل Deriv ومحرك استراتيجية وتأكيد بدء وسجل معاملات وحدود جلسة منفصلة. لا يظهر Demo في التطبيق إذا لم يُهيّأ على الخادم؛ وغياب إعداداته يبقي الخدمة Real-only.

كل محرك يبدأ مفصولاً ومتوقفاً. لا يتصل الخادم بـDeriv عند الإقلاع؛ يلزم أمر اتصال صريح للوضع المختار. ولا يشتري حتى يراجع المشغّل التأكيد الدقيق لذلك الحساب ويبدأه صراحةً. واجهة Android لا تتصل بـDeriv ولا تنفذ محلياً، ولا تحتفظ بـPAT أو سر حساب Deriv.

تتحقق عميلات Deriv من أن رابط OTP يطابق نوع الحساب تماماً: `/trading/v1/options/ws/real` لحساب Real و`/trading/v1/options/ws/demo` لحساب Demo. لا يمكن لخيار واجهة وحده تغيير نوع حساب الخادم. شروط إشارات CALL/PUT والاستراتيجية وحدود المخاطر السابقة لم تتغير. الحساب الحقيقي قد يخسر المال؛ Demo يستخدم رصيداً افتراضياً ولا يثبت ربحية Real.

تعرض اللوحة الشموع والعقد المفتوح من محرك الوضع المختار. التقييم التاريخي منفصل عن سجل الصفقات ويقيس دقة الاتجاه فقط، لا نتائج صفقات Demo ولا ربحية عقود Deriv. لا يعرض نسبة إذا كانت مدة العقد بوحدة تيك أو لا تتطابق تماماً مع إطار الشموع أو لم تتوفر البيانات الكافية.

## المتطلبات والنشر اليدوي

- Node.js 20 أو أحدث؛ `npm ci` ثم `npm start`.
- Render Web Service واحدة وقرص دائم مربوط عند `/var/data`؛ لا تستخدم replicas أو autoscaling. يمكن للمحركين العمل في العملية نفسها، ولكلٍ عميل وحالة مستقلة.
- هذا دليل يدوي فقط؛ لم يتصل هذا الإصدار بـRender ولم يُنشر. ارفع ملفات الحزمة يدوياً إلى مشروعك، واجعل `package.json` في جذر الخدمة، واضبط `npm ci` للبناء و`npm start` للتشغيل.
- لا تضع `.env` أو PAT أو `ADMIN_TOKEN` في GitHub أو Android أو عنوان URL. لا يُقرأ `.env` تلقائياً مع `npm start`؛ أدخل المتغيرات في إعدادات بيئة الخدمة. لا يستخدم هذا الإصدار `legacy authorize`.

## متغيرات البيئة

أسماء متغيرات Real الحالية لم تتغير:

| المتغير | الغرض |
|---|---|
| `DERIV_APP_ID` | App ID المستخدم مع PAT الحالي |
| `DERIV_PAT` | PAT الحالي لمسار Mma911؛ يحتاج صلاحية `trade` |
| `DERIV_ACCOUNT_ID` | معرّف حساب Options الحقيقي |
| `ADMIN_TOKEN` | سر إداري عشوائي، 24 حرفاً على الأقل |
| `STATE_FILE` | سجل Real على القرص الدائم، مثلاً `/var/data/scdp-real/state.json` |
| `DERIV_SYMBOL` | رمز السوق الافتراضي الاختياري |
| `PORT` | يحدده Render تلقائياً، أو 3000 محلياً |

لتفعيل Demo اختيارياً، اضبط **معرّف حساب Demo** ومسار حالة مختلفاً:

| المتغير | الغرض |
|---|---|
| `DERIV_DEMO_ACCOUNT_ID` | معرّف Options Demo، ويجب أن يختلف عن `DERIV_ACCOUNT_ID` |
| `STATE_FILE_DEMO` | سجل مستقل على القرص الدائم، مثلاً `/var/data/scdp-demo/state.json` |
| `DERIV_DEMO_PAT` | اختياري؛ PAT مستقل إذا لم يكن PAT الحالي مخولاً لحساب Demo |
| `DERIV_DEMO_APP_ID` | اختياري؛ App ID مع `DERIV_DEMO_PAT`؛ وإلا يستخدم `DERIV_APP_ID` |
| `DERIV_DEMO_SYMBOL` و`DERIV_DEMO_CURRENCY` | إعدادا بداية اختياريان لحساب Demo |

يمكن استخدام PAT الحالي لحساب Demo إذا كان يملك نطاق `trade` والوصول لذلك الحساب؛ وإلا أضف PAT وApp ID خاصين به في إعدادات Render فقط. لا تشارك الأسرار في الهاتف أو المحادثة. يجب أن تكون مسارات Real وDemo مطلقة ومختلفة على القرص الدائم. إذا غاب `DERIV_DEMO_ACCOUNT_ID` يعمل الخادم Real-only؛ وإذا بدأ إعداد Demo دون معرّف أو دون سجل مستقل يفشل التشغيل مغلقاً بدلاً من تفعيل إعداد جزئي.

تحقق من معرّف Demo عبر واجهة Deriv أو نقطة `GET /trading/v1/options/accounts` باستخدام صلاحية `trade`. لم نطلب هذه البيانات من Deriv في هذا العمل ولم نتحقق من حسابك.

## طريقة التشغيل عبر Android 1.6.0

1. حدّث الخادم يدوياً إلى v4.4.0، وأبقِ إعدادات Real الحالية وملف حالته كما هما. أضف إعدادات Demo الاختيارية أعلاه، ثم أعد تشغيل الخدمة بنفسك.
2. أدخل عنوان HTTPS ورمز `ADMIN_TOKEN` في التطبيق. لا تدخل PAT أو بيانات Deriv في Android.
3. اضغط «تحديث الحالة». يقرأ التطبيق `/modes`; إن لم يبلغ الخادم أن Demo مهيأ، يخفي خيار Demo ويستخدم Real فقط. Real هو الوضع المحدد افتراضياً.
4. اختر الوضع ثم اضغط «اتصال آمن» لذلك الوضع. الاتصال لا يبدأ التداول. اختر السوق والإعدادات واحفظها على الخادم، ثم اطلب تأكيداً جديداً واقرأ الحساب والسوق والمدة والرهان وحدود المخاطر والعبارة الدقيقة.
5. بدء Demo يحتاج عبارة `DEMO ... VIRTUAL FUNDS` وتأكيداً مستقلاً؛ بدء Real يحتاج عبارة `REAL MONEY`. كل بدء يدوي ومتصل بوضعه. يمكن إبقاء كلا المحركين يعملان على الخادم بالتتابع: اتصل وابدأ كل واحد على حدة، والتبديل في الهاتف لا يوقف الوضع الآخر.
6. زر الإيقاف يوقف المشتريات الجديدة للوضع المختار فقط ولا يلغي عقداً مفتوحاً أو شراءً أُرسل بالفعل. بعد انقطاع أو إعادة تشغيل الخدمة لا يستأنف أي وضع تلقائياً؛ افحص الحالة وسجل الحساب ثم أعد الاتصال والتأكيد والبدء يدوياً.

## واجهة الخادم

كل مسارات التحكم، عدا `GET /` للصحة العامة، تتطلب `Authorization: Bearer ADMIN_TOKEN`. الوضع الافتراضي عند حذف `mode` هو `real` حفاظاً على توافق التطبيق القديم. يقبل كل مسار خاص بالحساب `?mode=real` أو `?mode=demo`; ويرفض Demo إذا لم يكن مهيأً.

- `GET /modes` يعيد الأنماط المهيأة وحالة الاتصال دون فتح اتصال.
- `POST /connect?mode=demo` أو `POST /connect?mode=real` يطلب الاتصال الصريح، ويبقى التداول متوقفاً.
- `GET /status?mode=...`, `/settings?mode=...`, `/pnl?mode=...`, `/trades?mode=...`, و`/history?mode=...` تعرض بيانات ذلك الوضع فقط.
- `GET /markets?mode=...` و`GET /market-data?mode=...&symbol=...&granularity=60` تقرآن بيانات السوق من محرك الحساب المحدد. التقييم ضمن استجابة السوق دقة اتجاه تاريخية، وليس سجل صفقات Demo.
- `POST /settings?mode=...` يحفظ إعدادات ذلك الوضع فقط وهو متوقف وجاهز ولا يوجد عقد مفتوح أو شراء غير محسوم.
- `GET /confirmation?mode=...` ثم `POST /start?mode=...` ينفذان دورة تأكيد منفصلة. لا يمكن استخدام موافقة Real لبدء Demo أو العكس.
- `POST /stop?mode=...` و`POST /disconnect?mode=...` يخصان الوضع المختار. `/reconcile?mode=...` يخص شراءً غير محسوم لذلك الحساب فقط وبعد تحقق يدوي.

الحالة الدائمة تتضمن `mode` ومعرّف الحساب المجزأ؛ يرفض المحرك تحميل سجل وضع أو حساب مختلف. استخدم `STATE_FILE` لـReal و`STATE_FILE_DEMO` لـDemo، ولا تنسخ السجلين إلى الملف نفسه ولا تحذف السجل لتجاوز قفل شراء غير محسوم.

## الاختبارات وحدود التحقق

شغّل `npm test`. تشمل الاختبارات محاكاة محلية لاتصال Real وDemo، والتحقق من عنوان WebSocket، وعزل الحالة والتأكيد، وتوجيه API. لم يُجر اتصال حي بـDeriv أو Render، ولم يُنشر الخادم، ولم تُنفّذ صفقات، ولم نتحقق من صلاحية PAT أو معرّف Demo الخاص بك. يلزم اختبارك اليدوي بعد إدخال بيانات الحساب في بيئة الخادم.
